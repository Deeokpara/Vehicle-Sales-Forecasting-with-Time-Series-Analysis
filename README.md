 📈 Vehicle Sales Forecasting with Time Series Analysis

 Overview
This project analyzes historical vehicle sales data and builds forecasting models to predict future demand using ARIMA and Prophet.

Business Problem
Accurate forecasting helps businesses manage inventory, production, and demand planning effectively.

Approach
- Data Cleaning & Preparation
- Time Series Transformation
- ARIMA Modeling
- Prophet Modeling
- Model Comparison (MAE)
- Power BI Dashboard Visualization

Dashboard
The project includes an interactive Power BI dashboard showing:
- Historical Sales Trends  
- Forecast Comparison (ARIMA vs Prophet)
- Model Performance Metrics
- Business Insights

Results
- Both models capture trends effectively
- Prophet performs better in handling seasonality
- Forecast suggests stable future demand

Business Recommendations
- Increase inventory before peak periods
- Align marketing campaigns with demand cycles
- Continuously retrain models with new data

Tools Used
- Python (Pandas, Matplotlib)
- Statsmodels (ARIMA)
- Prophet
- Power BI
